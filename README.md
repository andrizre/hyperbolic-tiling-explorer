# Hyperbolic Tiling Explorer

Interactive explorer for regular `{p,q}` tilings of the hyperbolic plane, rendered
on the Poincaré disk with pure Canvas 2D — no libraries, no build step.

## Concept

The fundamental `{p,q}` polygon (p-gon, q meeting at every vertex) is computed
from its hyperbolic circumradius, then the whole tiling is generated by
reflecting it across its edges. Each reflection is an inversion in the geodesic
circle through the edge endpoints, represented as a Möbius transform over the
complex numbers (with input conjugation for the antiholomorphic part), composed
recursively. Tiles are deduplicated by exact vertex signature.

## Features

- `{p,q}` Schläfli sliders (invalid pairs auto-clamped to `1/p + 1/q < 1/2`)
- Recursion depth control with a 20k-tile safety cap
- 6 palettes, color-by-depth gradient or two-tone alternation
- Geodesic arcs on/off, disk spin animation, drag-to-rotate
- Scroll-wheel zoom (0.25×–8×) with double-click reset
- PNG export of the current canvas
- Live tile count readout

## Run

```sh
cd hyperbolic-tiling-explorer
python3 -m http.server 8000
# open http://localhost:8000
```

(Or just open `index.html` directly in a browser.)

## Verify

```sh
node test.js   # headless checks: reflections are involutions fixing their edges,
               # vertices stay in the unit disk, layer counts grow monotonically
```
